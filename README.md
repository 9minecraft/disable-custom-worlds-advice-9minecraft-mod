# Disable Custom Worlds Advice — Load Custom Saves Without Prompts

Disable Custom Worlds Advice 9minecraft Mod removes the experimental world warning screen whenever you load custom saves. It stops the game from interrupting your launch with confirmation boxes for data packs and custom world settings. You get straight into your world without having to click through extra prompt screens every single time.

Bypasses Warning Screens: Skips the experimental confirmation prompt directly upon opening a world. Loads saves faster by cutting out extra confirmation clicks.

## What this build is

An unofficial rebuild of **alxpettit**, **diskree**, **rdvdev2**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
